Meet App

React | Google Calendar API | AWS Lambda | Service Workers | Chart.js | GitHub Pages

The rationale behind this project was to harness the power of modern web development techniques by combining serverless architecture and Progressive Web Applications (PWA). This project was initiated to demonstrate the advantages of using a Test-Driven Development (TDD) approach and to build a highly responsive and reliable web application. Historically, traditional web applications required extensive backend maintenance and were not always optimized for offline usage. By leveraging serverless functions and PWA technologies, the application aims to deliver a superior user experience with minimal backend management.

The Problem

The primary objective was to build a serverless, progressive web application (PWA) with React that fetches upcoming events using the Google Calendar API.
The Aims were to:
Developing a user-friendly interface for accessing and visualizing event data.
Implement essential views and features derived from user stories.
Ensure the app is maintainable, readable, and showcases best practices in modern web development.

Tech Stack Explained

This project is a modern web application designed to provide users with information about upcoming events. The application is built using React and leverages serverless architecture with AWS Lambda for the authorization server. It integrates with the Google Calendar API to fetch event data and uses service workers to enable offline support and other PWA features. Data visualization is achieved using ReCharts, creating an engaging and informative user interface.

Lessons Learned

Creating Core Components and Views: These form the backbone of the application, providing essential functionality and user interfaces.
Goal: To implement the Main View, Event List View, Event Details View, Login View, and City Search View.
Skills and Tools: React, ES2015+, CSS, Google Calendar API, Chart.js, AWS Lambda, Service Workers.
What went well: Successfully implemented a responsive and offline-capable PWA with a high degree of test coverage.
What didn’t go well: Initial challenges with OAuth2 authentication flow, which required extensive debugging and adjustments.
Challenges: Ensuring seamless integration between serverless functions and the client-side application. This was solved by iterating on design and code refactoring.
Decisions: Utilized functional components and hooks for state management due to their simplicity and efficiency.
