Meet App

React Native | Expo &B Expo Go App | Gifted Chat | Google Firestore Database | AsyncStorage

This project aimed to create a fully functional chat application optimized for both Android and iOS platforms using React Native. The app was developed to provide users with a seamless chat experience, allowing them to exchange text messages, share images, and share their location in real-time. The choice of React Native, Expo, and Google Firestore Database as the tech stack facilitated the creation of a single codebase for both platforms, significantly reducing development time and effort.

The Problem

The primary objective was to To build a chat app for mobile devices using React Native. The app will provide users with a chat interface and options to share images and their location.
The Aims were to:
Developing a user-friendly interface for accessing and visualizing event data.
Implement essential views and features derived from user stories.
Ensure the app is maintainable, readable, and showcases best practices in modern web development.

Tech Stack Explained

This project is a native mobile application designed to provide users with a rich chat experience. The application is built using React Native, which allows for a single codebase to be used for both iOS and Android platforms. It leverages Expo for development and deployment, simplifying the process of building and testing the app. Google Firestore Database is used to store chat messages, images, and location data, enabling real-time synchronization and offline support.

Lessons Learned

Creating Core Components and Views: These form the backbone of the application, providing essential functionality and user interfaces.
Goal: To develop a single codebase that runs on both iOS and Android, ensure users can access their messages offline, and to provide a personalized and intuitive user experience.
Skills and Tools: React Native, Expo, Google Firestore.
What went well: Successfully created a responsive and feature-rich chat application with real-time capabilities and offline support.
What didn’t go well: Initial challenges with using the Expo Android simulator as it requires specific indentation and quotations to function properly
Challenges: Ensuring real-time synchronization and offline support.
Decisions: Chose Google Firestore for its real-time capabilities and offline support features.
